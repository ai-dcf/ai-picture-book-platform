# AI 绘本工作室 — 前端页面 UI/UX 功能设计

> 本文档从用户视角描述每个页面的 UI 展示与交互体验设计，不涉及技术实现细节。

### UI 与交互设计

| 交互元素 | UX 行为 |
|----------|---------|
| **顶部导航栏** | 固定吸顶，半透明毛玻璃效果；左侧显示Logo+Beta标识；右侧依次为导出按钮、通知图标、设置图标、用户头像（点击展开下拉菜单：个人资料 / 设置 / 退出登录）；未登录显示"登录"按钮 |
| **左侧项目边栏** | 固定宽度侧边栏，包含：<br>• 「我的项目」按钮<br>• 项目搜索框（支持按名称搜索）<br>• 项目列表按时间分组（最近 / 昨天 / 过去7天 / 过去30天 / 今年）<br>• 每个项目项显示：缩略图、标题、状态标签、更新时间 |
| **主区域 - 欢迎标题** | 居中展示大字号标题，右侧"以您的设计为基础"按钮可导入外部设计稿开始创作 |
| **主区域 - 创作输入区** | 核心交互卡片，包含：<br>• 多行输入框，提示"今天想创作什么样的绘本？"<br>• 参数选择区：目标年龄（自动/1-3/3-5/5-7/7-9）、预期页数（自动/8/12/16/24/32）、核心风格（自动/8种风格）三个下拉选择器<br>• 「✨ 一键优化」按钮：点击后AI润色输入的故事概要<br>• 右侧蓝色发送按钮：校验输入内容非空后可点击，点击后直接跳转创作台，自动进入故事架构阶段 |
| **主区域 - 快速模板** | 预设故事模板标签，点击自动填充对应故事概要到输入框 |
| **主区域 - 灵感区域** | 横向排列的灵感案例卡片，支持左右翻页查看更多；点击案例可查看详情并快速复用 |
| **项目列表交互** | hover时项目项高亮，点击直接进入对应项目的创作台；hover时显示删除按钮，点击弹出二次确认弹窗 |
| **加载态** | 项目列表加载时展示骨架项，灵感区域加载时展示骨架卡片 |
| **响应式** | 小屏幕下左侧项目边栏可折叠为仅图标模式，主区域自适应宽度

### UI 与交互设计

| **整体布局** | 居中卡片，最大宽度 448px，全屏垂直水平居中 |

| 交互元素 | UX 行为 |

```

### UI 与交互设计

| 交互元素 | UX 行为 |
|----------|---------|
| **双 Tab 切换** | "文本模型"与"图像模型"两个 Tab 页，各自独立管理 |
| **模型卡片列表** | 每个模型一张卡片，展示别名、策略标签、脱敏 API Key、连接状态徽章 |
| **连接状态徽章** | 4 种状态：灰色"未测试" / 绿色"连接正常 + xxms" / 黄色"连接不稳定" / 红色"连接失败" |
| **启用/禁用开关** | Switch 开关，关闭后模型不参与生成调用 |
| **新增模型** | 点击按钮弹出 Dialog 表单：选择厂商预设（火山引擎/智谱/OpenAI/DeepSeek 等）→ 自动填充模型名和 Base URL → 填写 API Key → 保存 |
| **厂商预设** | 下拉选择厂商后，模型名下拉自动展示该厂商可用模型列表；选择"自定义"则手动填写所有字段 |
| **编辑模型** | 点击编辑图标，弹出与新增相同的 Dialog，回填当前值 |
| **删除模型** | 点击删除图标，弹出 AlertDialog 二次确认 |
| **空状态** | 无模型时展示虚线边框卡片 + "当前还没有配置任何模型" + 新增按钮 |
| **加载态** | 加载时展示 3 张骨架卡片 |

## 七、创作台 `/studio`

> 创作台是核心页面，采用 5 阶段线性工作流，用户逐步完成绘本创作（项目初始化已整合到首页）。

### 整体布局

```
┌──────────────────────────────────────────────────────────┐
│ [Logo] 项目标题  [年龄][画风][页数][比例][状态]  💾 用户▼ │  ← TopBar
├────────┬─────────────────────────────────────────────────┤
│ ● 故事 │          阶段内容区域                             │
│ ● 分镜 │       （居中 max-w-3xl 或全宽）                  │
│ ● 素材 │                                                 │
│ ○ 逐页 │                                                 │
│ ○ 定稿 │                                                 │
│────────│                                                 │
│ 草稿中 │                                                 │
│ 0/5阶段│                                                 │
├────────┴─────────────────────────────────────────────────┤
│ ⚠️ 尚未配置文本模型和图像模型，请先前往模型设置页面配置   │  ← Banner（可选）
└──────────────────────────────────────────────────────────┘
```

### TopBar 交互设计

| 交互元素 | UX 行为 |
|----------|---------|
| **项目标题** | 左侧 Logo + 项目名，过长时截断 |
| **配置标签组** | 横向排列的 Badge：目标年龄、画风、页数、宽高比、项目状态（不同状态不同颜色边框） |
| **保存状态** | 图标 + 文字：云上传(保存失败) / 旋转(保存中) / 勾(已保存)，实时反映 |
| **项目设置弹窗** | 点击齿轮图标弹出 Dialog，可修改主题/年龄/页数/画风/比例；若已有下游内容，顶部黄色警告框提示修改影响 |
| **用户菜单** | 头像下拉菜单（个人资料 / 设置 / 退出登录） |

### 左侧边栏交互设计

| 交互元素 | UX 行为 |
|----------|---------|
| **5 阶段导航** | 每阶段一行：状态图标 + 阶段名称；当前阶段高亮蓝色背景 + 蓝色圆点；已完成阶段绿色勾；进行中旋转加载；待复查黄色警告；锁定阶段灰色半透明 + 不可点击 |
| **页面状态展开** | 进入阶段 4 后，在"逐页生成"下方展开每页的状态列表，每行一个圆点 + "第 N 页" + 状态文字 |
| **底部统计** | 展示项目状态、已完成阶段数(0/5)、已定稿页数、待复查数 |
| **折叠/展开** | 支持折叠为仅图标模式 |

### 模型缺失警告条

| 交互元素 | UX 行为 |
|----------|---------|
| **Banner** | 黄色背景警告条，图标 + "尚未配置文本模型/图像模型，请先前往模型设置页面添加模型配置"，链接可点击跳转 |



### 阶段 1：故事架构

```
┌───────────────────────────────────────────────┐
│  阶段 1 · 故事架构                             │

│  ┌─────────────────────────────────────────┐  │

│  └─────────────────────────────────────────┘  │

| 交互元素 | UX 行为 |
|----------|---------|
| **自动生成** | 进入创作台后自动触发 AI 生成，用户无需手动操作 |
| **手动重新生成** | "一键生成故事架构"按钮，生成中显示旋转图标 + "生成中…" |
| **故事大纲** | 文本展示区，只读 |
| **角色卡片** | 可折叠卡片，默认收起显示名称和描述首行；展开后可编辑描述文本；手动修改后标注黄色"已修改"标签；编辑时黄色警告"修改描述可能影响后续分镜拆页与素材设定" |
| **场景卡片** | 同角色卡片交互模式 |
| **情感曲线图** | 可视化折线图，横轴为故事进度，纵轴为情感强度；点击某个节点弹出编辑面板，可修改情感类型和强度值 |
| **确认按钮** | 角色 > 0、大纲非空、情感曲线 > 0、场景 > 0 时才可用；确认后进入阶段 2 |
| **下游影响** | 有下游内容时编辑操作触发黄色警告 |
