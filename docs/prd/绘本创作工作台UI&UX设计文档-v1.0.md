# AI绘本工作室 - 创作工作台 UI&UX设计文档 v1.0

## 一、设计规范总览
### 1.1 设计原则
- **简洁高效**：减少不必要的操作步骤，引导用户专注创作
- **视觉统一**：全平台保持一致的设计语言和交互逻辑
- **儿童友好**：整体风格明亮、柔和，符合绘本创作的产品定位
- **响应式适配**：完美适配桌面端和平板设备

### 1.2 配色规范
| 颜色类型 | 色值 | 使用场景 |
|----------|------|----------|
| 主色调 | #6366F1 | 高亮按钮、选中状态、主要操作入口 |
| 辅助色-成功 | #10B981 | 成功状态、已完成标识、✅标签 |
| 辅助色-警告 | #F59E0B | 待复查状态、提示信息、⚠️标签 |
| 辅助色-错误 | #EF4444 | 错误提示、失败状态、❌标签 |
| 中性色-背景 | #FFFFFF | 页面主背景 |
| 中性色-卡片背景 | #F9FAFB | 编辑框、卡片背景 |
| 中性色-边框 | #E5E7EB | 边框、分割线 |
| 中性色-正文 | #111827 | 主要文字内容 |
| 中性色-辅助文字 | #6B7280 | 提示文字、次要信息 |
| 中性色-禁用文字 | #9CA3AF | 禁用状态文字 |

### 1.3 字体规范
| 字体层级 | 字号 | 字重 | 使用场景 |
|----------|------|------|----------|
| 页面大标题 | 20px | 600 | 各阶段页面标题 |
| 二级标题 | 16px | 600 | 编辑区模块标题、卡片标题 |
| 正文 | 14px | 400 | 主要文字内容、输入框文字 |
| 辅助文字 | 12px | 400 | 提示文字、标签、状态标识 |
| 极小文字 | 10px | 400 | 小标签、状态提示、底部说明文字 |
| 字体家族 | 优先使用系统无衬线字体：Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif |

### 1.4 布局规范
- 页面最小宽度：1200px（桌面端），768px（平板端）
- 左右栏布局比例：左侧导航栏占宽200px，右侧内容区占满剩余宽度
- 内容区左右内边距：24px，上下内边距：20px
- 模块间距：20px，模块内元素间距：12px
- 圆角规范：按钮/卡片/输入框统一使用8px圆角，小标签使用4px圆角
- 阴影规范：卡片悬浮使用柔和阴影：`0 2px 8px rgba(0,0,0,0.06)`

## 二、全局组件设计规范
### 2.1 顶部导航栏
```

│ 📚 AI绘本工作室 BETA                                          ⚙️设置 👤用户 ▼ │
```

### 2.2 步骤导航栏
```
┌──────────────────────────────────────────────────────────────────────────────┐
● 阶段1·故事架构 │ ○ 阶段2·分镜拆页 │ ○ 阶段3·素材准备 │ ○ 阶段4·页面创作 │ ○ 阶段5·导出发布

```
- 高度：52px，背景色：#F9FAFB，底部边框：1px solid #E5E7EB
- 步骤项：每个步骤左右内边距16px，间距24px
- 状态样式：
  - 当前阶段：蓝色圆点+蓝色文字+底部2px蓝色边框
  - 已完成阶段：绿色对勾图标+灰色文字
  - 未完成阶段：灰色圆点+灰色文字

### 2.3 全局操作栏
```
┌──────────────────────────────────────────────────────────────────────────────┐

└──────────────────────────────────────────────────────────────────────────────┘
```
- 高度：56px，背景色：#FFFFFF，底部边框：1px solid #E5E7EB
- 操作按钮靠右对齐，间距12px
- 主要操作按钮使用主色调背景，次要操作按钮使用白色边框按钮

### 2.4 左侧导航栏
- 宽度：200px，背景色：#FFFFFF，右侧边框：1px solid #E5E7EB
- 列表项：上下内边距10px，左右内边距16px，圆角8px
- 选中项：背景色#6366F110，文字蓝色，左侧2px蓝色边框
- hover项：背景色#F3F4F6
- 分组标题：12px字号，灰色大写，上下内边距12px，左右内边距16px

### 2.5 按钮规范
| 按钮类型 | 样式 | 使用场景 |
|----------|------|----------|
| 主按钮 | 主色调背景，白色文字，圆角8px，高度36px | 主要操作：下一步、生成、导出 |
| 次按钮 | 白色背景，灰色边框，黑色文字，圆角8px，高度36px | 次要操作：重新生成、优化、编辑 |
| 小按钮 | 高度28px，字号12px | 卡片内操作、小区域按钮 |
| 图标按钮 | 32x32px，圆角6px，hover背景高亮 | 纯图标操作按钮 |
- 按钮禁用状态：透明度0.5，鼠标样式not-allowed
- 加载状态：按钮文字左侧加旋转动画的loading图标，文字变为「XX中…」

### 2.6 输入框规范
- 高度：多行输入框最小高度80px，根据内容自动撑开
- 边框：默认1px solid #E5E7EB，focus时边框变为主色调，outline 2px solid #6366F120
- 背景色：#FFFFFF，hover时背景色#F9FAFB
- 圆角：8px，内边距：12px
- 占位文字颜色：#9CA3AF，字号14px

### 2.7 状态标签规范
| 状态 | 样式 | 示例 |
|------|------|------|
| 已完成/已生成 | 绿色背景，白色文字，圆角4px，10px字号 | ✅ 已生成 |
| 待复查 | 黄色背景，白色文字，圆角4px，10px字号 | ⚠️ 待复查 |
| 生成中 | 蓝色背景，白色文字，圆角4px，10px字号，加载动画 | 🔄 生成中 |

## 三、各阶段页面设计说明
### 3.1 阶段1·故事架构页面设计
#### 视觉布局
- 左侧菜单：5个菜单项（故事架构、故事大纲、情感曲线、角色、场景）
- 右侧编辑区：每个菜单项对应独立的编辑区域
  - 故事大纲：大尺寸多行输入框，高度200px
  - 情感曲线：可视化折线图组件，支持点击节点编辑
  - 角色/场景：可折叠卡片列表，每个卡片包含名称和描述编辑框
- 底部操作按钮：「🪄 重新生成」「✨ AI优化」按钮靠左对齐

#### 交互效果
- 左侧菜单点击切换时，右侧内容区淡入淡出过渡动画（200ms）
- 输入框focus时有轻微放大效果（scale: 1.01）
- 卡片折叠/展开时有平滑的高度过渡动画

## 四、交互效果规范
### 4.1 通用动效
- 所有hover状态变化过渡时间：150ms，ease-out缓动
- 所有展开/折叠、切换过渡时间：200ms，ease-in-out缓动
- 加载动画：旋转动画，1s一圈，线性缓动
- 成功/错误提示toast：淡入淡出+轻微上浮动画，3s后自动消失

### 4.2 反馈规范
- 操作成功：绿色toast提示，自动消失
- 操作失败：红色toast提示，带重试按钮，需手动关闭
- 加载状态：按钮/区域显示加载动画+文字提示，操作期间禁用重复点击
- 内容保存：修改内容后，顶部短暂显示「已保存」提示，无需用户干预

### 4.3 键盘快捷键支持
- `Ctrl/Cmd + S`：手动触发保存（虽然是自动保存，仍支持快捷键）
- `←/→`：阶段5翻页浏览时支持左右箭头快捷键
- `Esc`：关闭所有弹窗/预览模态框

## 五、响应式适配规范
### 5.1 平板端适配（768px - 1199px）
- 左侧导航栏宽度缩小到160px，文字字号缩小1px
- 内容区内边距缩小到16px
- 历史记录缩略图大小缩小到60x60px
- 按钮宽度自适应，不再固定宽度
- 阶段5预览区大图最大高度调整为450px

### 5.2 移动端适配（<768px）
- 本产品定位为桌面端创作工具，移动端仅支持查看和导出，不支持编辑功能
- 移动端布局改为上下结构，导航栏改为顶部下拉菜单
- 预览区大图宽度100%，自适应屏幕宽度

## 六、图标规范
- 统一使用Lucide图标库，图标大小统一：
  - 导航栏/按钮图标：18px
  - 小标签/状态图标：14px
  - 小按钮图标：16px
- 图标颜色：与旁边文字颜色保持一致
- 图标与文字间距：4px

## 七、设计验收标准
1. 所有视觉元素与本设计文档规范一致，颜色、字号、间距、圆角误差≤1px
2. 所有交互效果流畅，无卡顿，动效时间符合规范
3. 响应式适配在不同尺寸屏幕下布局正确，无错位、重叠
4. 所有状态都有明确的视觉反馈，用户操作路径清晰
5. 整体视觉风格统一，符合儿童绘本产品的明亮、友好定位
