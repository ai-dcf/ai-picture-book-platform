## 背景

当前 `Stage6Finalize.tsx` 主要围绕正文页进行“编辑定稿与导出”操作，但存在三个明显问题：

- 列表中缺少封面卡片，封面无法在该阶段统一预览和导出。
- 页面缩略图使用固定正方形容器展示，无法反映页面真实比例。
- 导出模块当前使用固定正方形画布，导致 `16:9`、`3:4` 等页面在导出后被拉伸成 `1:1`。

这让 `Stage6` 无法完整承担“最终检查、预览和导出整本绘本”的职责。

## 目标

- 在 `Stage6Finalize` 中将封面和正文页统一展示与导出。
- 让封面与页面缩略图按各自真实比例显示。
- 支持点击封面或页面缩略图查看大图预览。
- 让导出的 PNG 和 ZIP 结果与封面/页面实际比例一致。
- 尽量复用已有状态和导出基础设施，不扩展不必要的数据结构。

## 用户已确认的规则

- 封面作为与正文页同级的卡片，放在列表最前面。
- 封面需要支持预览和单独导出。
- 批量导出时封面一并导出，并排在正文页之前。
- `Stage6Finalize` 中的缩略图容器按封面/页面原始比例显示，而不是固定正方形。
- 点击缩略图可以查看大图预览。
- 导出结果需要跟页面实际比例一致。

## 方案

### 1. 改动边界

- 修改 `src/components/studio/stages/Stage6Finalize.tsx`
- 修改 `src/modules/studio/infrastructure/export-book.ts`
- 不修改以下内容：
  - 页面生成逻辑
  - 编辑页内部编辑能力
  - 项目存储结构
  - 页面与封面的基础字段定义，除非已有导出函数入参需要最小补充

### 2. 封面并入 Stage6 列表

- 在 `Stage6Finalize` 中将封面作为一个独立卡片插入正文页列表最前面。
- 封面卡片与正文页卡片保持同类视觉层级，但文案区分为：
  - 标题：`封面`
  - 状态：沿用封面现有状态字段
  - 描述：优先展示封面标题或封面画面说明
- 封面卡片支持：
  - 缩略图预览
  - 点击看大图
  - 单独导出 PNG
- 正文页卡片继续保留“进入本页编辑定稿”和“导出本页 PNG”。

### 3. 缩略图按真实比例显示

- 当前缩略图使用固定正方形尺寸，不符合页面真实比例。
- 调整为根据封面或页面自身 `aspectRatio` 渲染缩略图容器。
- 容器比例规则：
  - `16:9` 显示为横版比例
  - `3:4` 显示为竖版比例
  - 若后续支持更多比例，则复用统一比例映射逻辑
- 图片在比例容器内继续使用现有图片展示方式，但容器本身先正确反映比例。
- 这样用户在 `Stage6` 中能直接看出封面和正文页的真实版式。

### 4. 大图预览交互

- 为 `Stage6Finalize` 增加缩略图点击预览能力。
- 交互方式复用项目中现有的 `Dialog` / `DialogContent` 模式。
- 点击封面或正文页缩略图时，弹出对应大图：
  - 封面显示封面图
  - 正文页显示当前页插画
- 预览弹窗只承担查看作用，不在该弹窗中承载编辑、导出或切页逻辑。

### 5. 导出结果按实际比例输出

- 当前 `export-book.ts` 使用固定正方形画布，需要调整为按目标比例计算导出宽高。
- 导出尺寸策略：
  - 保留一个统一的长边基准尺寸
  - 根据 `aspectRatio` 动态换算宽高
  - 例如：
    - `16:9` -> `2048 x 1152`
    - `3:4` -> `1536 x 2048`
- 文字框位置继续复用百分比布局，但计算逻辑改为：
  - `x`、`w` 基于 `canvas.width`
  - `y`、`h` 基于 `canvas.height`
- 字号、圆角、内边距等导出绘制参数也需要从固定正方形基准改为与实际画布宽高联动，避免横图和竖图导出时视觉失衡。

### 6. 封面导出

- 扩展导出模块，使其支持封面单独导出。
- 封面导出可复用页面导出链路，但导出入参需要同时支持：
  - `cover`
  - `coverAspectRatio`
  - 封面预览图地址
- 单独导出封面时，命名规则建议为：
  - `00-项目名-封面.png`
- 若封面未生成，则封面卡片导出按钮保持禁用或按现有错误提示逻辑提示“无法导出”。

### 7. 批量导出包含封面

- 调整批量导出逻辑，让封面参与 ZIP 打包。
- 打包顺序：
  - 封面
  - 第 1 页
  - 第 2 页
  - ...
- 文件命名建议：
  - 封面：`00-项目名-封面.png`
  - 页面：延续现有页码命名规则
- 若封面缺失：
  - 不阻断正文页打包
  - 可按“跳过”或“失败”策略处理，但应保证正文页仍能导出
- 建议将封面纳入与正文页一致的成功 / 失败 / 跳过统计逻辑中，但文案中明确区分“封面”和“第 N 页”。

### 8. Stage6 页面统计与状态

- 当前顶部统计区可以保持大体布局不变。
- 统计逻辑是否把封面纳入“生成完成”计数，需要保持表达清晰：
  - 若继续只统计正文页，则文案维持“生成完成 3 / N”
  - 若封面也纳入，则文案需改成“封面 + 正文页生成进度”
- 最小实现建议：
  - 保持现有顶部正文页统计口径不变
  - 仅在列表区单独展示封面卡片
- 这样可以减少对既有项目状态文案的干扰。

### 9. 兼容性

- `Stage6Finalize` 保持原有总体结构，不需要整页重做。
- 编辑页中的导出入口会继续复用 `export-book.ts`，因此比例导出修复会同步生效。
- 现有正文页导出按钮逻辑可复用，不需要改动调用方式太多，只需让导出基础设施接受比例信息与封面导出入参。

## 涉及文件

- `src/components/studio/stages/Stage6Finalize.tsx`
  - 封面卡片并入列表
  - 缩略图按比例显示
  - 增加大图预览交互
  - 增加封面单独导出入口
- `src/modules/studio/infrastructure/export-book.ts`
  - 导出画布按实际比例计算
  - 支持封面单独导出
  - 批量导出纳入封面并调整文件命名

## 验收标准

- `Stage6Finalize` 列表最前面显示封面卡片。
- 封面和正文页缩略图按各自真实比例显示，而不是统一正方形。
- 点击封面或正文页缩略图可以查看对应大图。
- 单独导出正文页时，导出图片比例与页面真实比例一致。
- 单独导出封面时，导出图片比例与封面真实比例一致。
- 批量导出 ZIP 时包含封面，并排在正文页前。
- 封面缺失时不会阻断正文页的批量导出。

## 风险与取舍

- 将封面纳入批量导出后，导出结果统计和提示文案会稍微复杂，但能换来更完整的整书导出体验。
- 缩略图改为按比例显示后，卡片内部布局可能需要微调，以适配横版和竖版不同视觉高度。
- 保持顶部统计口径不变能减少改动范围，但会让封面不计入统计数字；这是最小实现下可接受的取舍。
